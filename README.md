### Запуск проекта
```bash
docker compose up -d --build
```

При поднятии контейнера app исполняются миграции  
Документация доступна по [http://localhost:8080/swagger/](http://localhost:8080/swagger/)  

Все настройки берутся из .env  
```
APP_PORT=8080

DB_HOST=db
DB_PORT=5432
DB_USER=user
DB_PASSWORD=pass
DB_NAME=mydb
DB_SSLMODE=disable
```

### Логика добавления подписок
Дата начала и окончания считаются включительными.

Если у нас добавляется незакрытая подписка (endDate null):
- Не должно быть других незакрытых подписок (иначе пересечение будет)
- Закрытые подписки должны быть раньше(до) (иначе будет перечесение)

Если у нас добавляется закрытая подписка:
- Она не пересекается с закрытыми подписками
- Она не пересекается с открытыми подписками
